🚀 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Clone the repository
   $ git clone https://github.com/emkamal/save-image-tabs.git

2. Open Chrome and go to chrome://extensions/

3. Enable "Developer mode" (toggle in top-right)

4. Click "Load unpacked" and select the folder

5. Test the extension:
   - Open some image tabs
   - Click extension icon
   - Click "Save All Images"

6. Start customizing:
   - Edit manifest.json for name/permissions
   - Modify popup/popup.html for UI
   - Update background/background.js for logic
